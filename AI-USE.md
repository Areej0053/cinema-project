# AI Usage Documentation — CineVerse

## 1. Project Information

**Project Name:** CineVerse — Movie Discovery Web Application

**Project Type:** University Group Project

**Milestone:** 1

**Team Members:** Areej, Waed, and Sara

## 2. Purpose of AI Assistance

During the development of CineVerse, AI tools were used as development assistants to support learning, problem-solving, code implementation, debugging, user interface improvements, and project documentation.

AI assistance helped the team understand development concepts, troubleshoot technical issues, and improve the overall quality of the application.

## 3. AI Tools Used

**ChatGPT (OpenAI)**

ChatGPT was used to provide explanations, code suggestions, debugging guidance, UI/UX recommendations, and documentation support.

## 4. Areas Where AI Was Used

### 4.1 Project Setup and GitHub

AI assistance was used to explain:

- React and Vite project structure.
- GitHub repositories, branches, commits, and pull requests.
- How to combine work from multiple team members.
- How to resolve merge conflicts.
- How to test and build the application.

### 4.2 React Development

AI provided guidance and code suggestions for:

- React components and JSX.
- React Router navigation.
- Movie cards and movie details pages.
- Movie collections and expandable sections.
- Search, filtering, and sorting functionality.
- Component organization and reusable interfaces.

### 4.3 User Interface and Design

AI helped improve:

- The Explore page layout.
- The About page design.
- The CineVerse header and branding.
- Login and registration interfaces.
- Responsive layouts for mobile devices.
- CSS styling and visual consistency.

### 4.4 Debugging and Testing

AI was used to assist with:

- Identifying and fixing React development errors.
- Understanding terminal messages.
- Reviewing frontend validation.
- Testing application navigation.
- Running production builds.
- Troubleshooting Git and deployment issues.

### 4.5 Deployment

AI provided step-by-step guidance for deploying CineVerse using Render, including:

- Build and publish settings.
- React Router rewrite configuration.
- GitHub integration.
- Deployment verification.

### 4.6 Documentation

AI assisted with preparing project documentation, including:

- README.md
- AI-USE.md
- Development and setup instructions
- Submission preparation

## 6. Human Review and Testing

AI-generated suggestions and code were incorporated into the project through the development workflow.

The team remained responsible for reviewing the application, testing its functionality, resolving integration issues, and verifying the final results.

Testing included:

- Navigation between application pages.
- Movie search, filtering, and sorting.
- Expandable movie collections.
- Movie details and related movie navigation.
- Login and registration form validation.
- Responsive page layouts.
- Production build verification.
- Deployment checks.

## 7. Limitations

AI-generated suggestions may contain errors or require modifications before use.

CineVerse currently uses a local JavaScript movie dataset, and authentication interfaces perform frontend validation only.

Real authentication, database integration, and additional backend functionality are not part of the current implementation.

## 8. AI Usage Declaration

AI tools were used as supporting resources during the development of CineVerse Milestone 1.

AI contributed explanations, code suggestions, interface improvements, troubleshooting assistance, and documentation drafts.

The team is responsible for the final submitted project and its functionality.
